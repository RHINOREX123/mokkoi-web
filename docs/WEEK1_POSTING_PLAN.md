## Recording Tips

1. **Screen recorder**: Use OBS or built-in screen recorder
2. **Resolution**: Record at 1080x1920 (vertical) for X video OR 1920x1080 (horizontal) — horizontal works better for showing the full canvas
3. **Speed up boring parts**: 2x speed on typing, normal speed on generation
4. **No voiceover needed**: Let the screen speak. Add text overlays if needed.
5. **Music**: Optional — lo-fi or tech-style background music. Keep it subtle.
6. **Trim aggressively**: 30 seconds > 45 seconds. Shorter = more replays.
7. **First 3 seconds matter**: Start with the action, not a logo intro.
